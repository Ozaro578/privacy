Karte schon auf einem anderen Handy? Code hier eingeben, dann läuft sie auch hier weiter.

  • 🍵 Pro gekauftem Matcha-Drink oder Açaí Bowl gibt es an der Theke einen Stempel. Einfach den Code zeigen.
  • 🎉 Bei 10 Stempeln ist ein Matcha Latte (oder ein Bowl-Topping) gratis. Danach geht die Karte von vorn los.
  • 📲 Die Karte ist in deinem Browser gespeichert. Als App auf dem Startbildschirm hast du sie immer dabei. Den Code am besten notieren oder einen Screenshot machen.
  • 🔒 Keine Anmeldung, keine Daten: Nur der Code und die Stempel werden gespeichert. Nicht übertragbar, kein Bargeldwert, nur im Laden in Heilbronn.

📲 Als App immer dabei

Website zum Startbildschirm hinzufügen, dann liegt die Stempelkarte neben deinen anderen Apps.
