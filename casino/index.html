So funktioniert's

  • 1024 Wege (5 Reihen: 3125): gleiche Symbole auf benachbarten Walzen von links, egal in welcher Reihe.
  • Kaskaden: Gewinnsymbole verschwinden, neue fallen nach. Jede Kaskade erhöht den Titan‑Multiplikator: x1 · x2 · x3 · x5.
  • Wild (Titan) ersetzt alle Symbole außer Tresor, Münze und Schlüssel.
  • 🔑 Bronze: Mystery, alle Symbole einer Sorte werden zu einem höheren Symbol. Silber: die ganze Walze wird Wild. Gold: Ascension, das Raster wächst für diesen Dreh auf 5 Reihen. Jeder Schlüssel wird selbst zum Wild.
  • 3+ Tresore zahlen 2x / 10x / 50x und starten Freispiele mit Wahl: Sturm, Krieger oder Titan. 3 Tresore in den Freispielen: +5 Spins.
  • 6+ Münzen starten Vault Rush: 3 Respins, Münzen bleiben kleben, jede neue Münze setzt die Respins zurück. Sammler‑Münze zahlt alle anderen Münzen noch einmal. Voller Tresor: 2500x.
  • Max‑Gewinn: 5000x Einsatz pro Runde.
